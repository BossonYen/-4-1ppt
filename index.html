💭 想一想：生活中的選擇結構

在學校的生活中，有沒有什麼概念或是實例有用到選擇結構的呢？例如：要及格者成績需要達 60 分，所以如果沒有 60 分則判定為不及格，否則為及格。

因此在設計程式時，我們希望能夠依據條件的成立與否來決定要執行特定程式或順序，我們稱之為選擇結構。

在講選擇結構之前，是不是通常會需要一個符號（例如菱形條件判斷）來表示是否有達到、高於或低於某個程度來做判斷？程式需要先學會「如何做判斷」，來比較數值是否達到、高於或低於某個標準。例如：要及格者成績需要達 60 分，所以如果沒有 60 分則判定為不及格，否則為及格。

接下來，我們就來看看如何透過流程圖與 if...else 語法實現這個概念！

流程圖常用符號與繪圖工具介紹

在動手寫程式之前，必須先透過數位工具繪製簡單的流程圖，讓程式的條件判斷邏輯清楚呈現。

符號名稱圖形外觀描述功能與用途說明
開始 / 結束符號圓角矩形 / 橢圓表示整個程式邏輯流程的起點（Start）或終點（End）。
決策 / 條件菱形 (Diamond)用於選擇結構的條件判斷。通常會有兩條出路（True / False）。
設定 / 程序長方形 (Rectangle)用來進行資料的運算或一般處理程序。
輸出 / 輸入平行四邊形用來表示資料的輸入或結果的輸出。

成績及格判斷（>=60 分）主題解析

#include<iostream>
using namespace std;
int main() {
    int score = 0;
    cout << "請輸入學期成績: ";
    cin >> score;
    
    if (score >= 60) {
        cout << "此學生成績及格" << endl;
    } else {
        cout << "此學生成績不及格" << endl;
    }
    return 0;
}

生活化進階範例：放颱風假標準判斷

氣象預報標準：「依據氣象預報，平均風力可達 7 級以上 或 陣風可達 10 級以上」即符合放假標準。

if (avgWind >= 7 || gustWind >= 10) {
    cout << "放颱風假" << endl;
} else {
    cout << "不放颱風假" << endl;
}

if 與 if...else 選擇結構架構說明

if (判斷條件) {
    // 條件成立（True）時執行
} else {
    // 條件不成立（False）時執行
}

認識關係與邏輯運算子

運算子名稱說明
>=大於或等於檢查是否大於或等於指定數值
&&邏輯與 (AND)多個條件必須同時成立
||邏輯或 (OR)多個條件只要有一個成立

⚠️ 學生最易犯錯的觀念與寫程式陷阱

陷阱一：把「等於 (==)」誤寫成「指定 (=)」

一個 = 是賦值，兩個 == 才是比較相等。
