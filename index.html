🤔 生活中的選擇結構

問：想一想，在學校生活中，有沒有什麼概念或實例有用到選擇結構？

👉 例如：成績需要達 60 分，若沒有 60 分則判定為不及格，否則為及格。

✏️ 思考填空練習：

  • 情況：考試成績結算
  • 條件：成績 < ______
  • 選擇結構問句：如果分數低於 60 分，則顯示 ______，否則顯示 ______。

💡 選擇結構定義：當我們希望依據條件成立與否來決定執行特定程式或順序時，即稱為選擇結構。

🔢 關係運算子 (Relational Operators)

電腦使用「關係運算子」比較數值是否達到或低於標準。比較結果只有兩種可能性：

成立：回傳 ______ (內部值為 ______)
不成立：回傳 ______ (內部值為 ______)
符號運算子名稱範例代表意義
>大於5 > 1檢查 5 是否大於 1 (True)
<小於1 < 5檢查 1 是否小於 5 (True)
>=大於或等於Price >= 100Price 至少為 100
<=小於或等於Price <= 100Price 至多為 100
==等於 (注意是雙等號)Price == 100檢查 Price 是否剛好 100
!=不等於5 != 1檢查 5 是否不等於 1 (True)

📐 流程圖常見符號與說明

在撰寫程式前先繪製流程圖，能協助釐清邏輯與程式執行順序：

符號圖案 名稱 代表意義
開始 / 結束 端點符號（圓角矩形），代表程式的起點與終點。
程式執行方向 流程線（箭頭），指示程式流程執行的順序與方向。
設定 / 程序 處理框（長方形），用於變數設定或資料算術運算。
決策 / 條件 判斷框（菱形），條件判斷區，分出 True / False 分支。
輸出 / 輸入 資料框（平行四邊形），用於資料的讀取 (Input) 或顯示 (Output)。
連接點 圓形，用於連接不同頁面或複雜交叉的流程線。
預定義流程 / 副程式 雙邊加豎線長方形，代表呼叫已定義好的函式或模組。

✏️ 動手做練習：

輸入一個數字，如果輸入的數字大於 0 則顯示正數，反之為負數。

1. if 敘述 (單向選擇)


#include <iostream>
using namespace std;

int main() {
    int num = 10;
    if (num > 0) {
        cout << "10為正數";
    }
    return 0;
}

👇 點擊進行逐行解說：

📋 語法格式

if (判斷條件) {
    敘述主體;
}

條件成立執行，不成立則跳過。

👈 點擊左側按鈕觀看詳細解析！

2. if...else 敘述 (雙向選擇)


#include <iostream>
using namespace std;

int main() {
    int num = 0;
    cin >> num;
    if ((num % 2) == 0) {
        cout << "此數能被2整除" << endl;
    } else {
        cout << "此數不能被2整除" << endl;
    }
    return 0;
}

👇 點擊進行逐行解說：

📋 語法格式

if (條件) {
    敘述1; /* 成立執行 */
} else {
    敘述2; /* 不成立執行 */
}
👈 點擊左側按鈕觀看詳細解析！

📝 課後練習測驗 (1 ~ 3 題)

Q1. 成績及格判斷：空格 A 應填入何者？

if ( ______A______ ) { cout << "此學生成績及格"; }

解答： score >= 60
Q2. 體重判斷：體重超過 90kg 印出過重，反之正常。
解答：
if (weight > 90) { cout << "此學生體重過重" << endl; }
else { cout << "此學生體重正常" << endl; }
Q3. BMI 計算結果輸出：(weight=63.5, height=1.73)
解答： BMI ≈ 21.2169，符合 18.5 <= BMI < 24，輸出：
此學生BMI正常，BMI結果為: 21.2169

🎮 課後練習 Q5：猜數字遊戲流程圖

題目說明：魯迪與洛琪希猜數字 (1~100)。比較兩人誰猜的數字比較接近目標。假設沒有平手：若魯迪較接近則輸出魯迪贏，反之則輸出洛琪希贏。

總結

  • 關係運算子比較結果為 True (1) 或 False (0)。
