1. 認識選擇結構與生活反思

思考：在學校生活中，是否有依據條件決定執行順序的例子？

例如：成績達 60 分為及格，未達 60 分則為不及格。

舉例反思（請學生思考後回答）：

情況： ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿ 體育課測驗 800 公尺跑步

條件： ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿ 時間小於等於 240 秒

選擇結構問句： ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿ 如果跑步時間小於等於 240 秒則通過，否則不通過。

2. 關係運算子 (Relational Operators)

電腦使用關係運算子比較兩個數值或變數：

符號運算子名稱範例
>大於5 > 1
<小於1 < 5
>=大於等於Price >= 100
<=小於等於Price <= 100
==等於 (相等)Price == 100
!=不等於5 != 1

比較結果只有兩種可能性：

  • 成立：回傳 True (內部儲存為 1)
  • 不成立：回傳 False (內部儲存為 0)

4. if 敘述（單向選擇）

👇 點擊程式碼各行查看解析：

#include <iostream>
using namespace std;
int main() {
  int num = 10;
  if (num > 0) {
    cout << "10為正數";
  }
  return 0;
}
💡 請點擊左側程式碼內容檢視說明。

5. if...else 敘述（雙向選擇）

👇 點擊程式碼檢視說明：

int num = 0;
cout << "請輸入一個整數: ";
cin >> num;
if (num % 2 == 0) {
  cout << "此數能被2整除" << endl;
}
else {
  cout << "此數不能被2整除" << endl;
}
💡 請點擊左側程式碼檢視講解。

6. if...else if...else（多重選擇）

if (score >= 90) {
  cout << "優秀 (A)";
}
else if (score >= 60) {
  cout << "及格 (B)";
}
else {
  cout << "不及格 (C)";
}
💡 點擊左側程式碼，了解多重判斷由上而下的執行流程。

🧠 課後檢測 (1 ~ 3 題)

Q1. 成績判斷空格 A 應填入？

答案：score >= 60

Q2. 體重判斷超過 90kg 過重，否則正常：

答案：if (weight > 90) { cout << "過重"; } else { cout << "正常"; }

Q3. weight=63.5, height=1.73，BMI 程式輸出結果？

答案：此學生BMI正常，BMI結果為: 21.2169

🔧 課後練習 4：程式除錯 (共 5 處錯誤)

錯誤行數原程式碼問題修正後正確程式碼
第 9 行 賦值符號 = 誤用 if (num == (int)num)
第 10 行 結尾缺少分號 ; cout << num << " 是整數。" << endl;
第 11 行 else 後面不應接條件式 else { (或改用 else if)
第 1-2 行 未包含標準標頭檔與命名空間 #include <iostream>
using namespace std;
第 15 行 return 0 漏掉分號 ; return 0;

總結

  • 單一條件判斷 ➔ 使用 if。
  • 二選一條件分支 ➔ 使用 if...else。
  • 多重條件（範圍/階梯判斷） ➔ 使用 if...else if...else。
  • 關係運算子注意：比較相等務必使用 ==（非賦值 =）。
