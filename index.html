1. 什麼是選擇結構？

在學校生活中，有沒有什麼概念或是實例有用到選擇結構的？

範例：成績達到 60 分判定為及格，否則判定為不及格。

舉例反思（點擊黃色按鈕查看答案）：

情況：請學生發表（如：買滿額折扣商品）

條件：消費金額滿 1000 元

問句：如果消費滿 1000 元則打 9 折，否則維持原價。

💡 結論：當我們希望依據條件成立與否來決定執行特定程式時，稱之為選擇結構。

2. 關係運算子與比較

程式需要先學會「如何做判斷」，利用運算子來比較數值。

符號運算子名稱範例
>大於5 > 1
<小於1 < 5
>=大於等於Price >= 100
<=小於等於Price <= 100
==等於Price == 100
!=不等於5 != 1

判斷結果（點擊揭曉）：

成立：回傳 True（內部儲存為 1）

不成立：回傳 False（內部儲存為 0）

5. if 敘述

if (判斷條件) {
    敘述主體;
}

說明：如果括號中的判斷條件成立，就會執行後面的敘述；不成立則不執行。

範例：判斷數字 10 是否為正數

int num = 10;
if (num > 0) {
    cout << "10為正數";
}
  • Line 6: 宣告整數變數 num = 10
  • Line 7: 檢查 num > 0，因為 10 > 0 條件成立 (true)
  • Line 9: 執行印出 "10為正數"

6. if...else 敘述

if (判斷條件) {
    敘述主體 1; /* 條件成立執行 */
} else {
    敘述主體 2; /* 條件不成立執行 */
}

範例：輸入整數判斷能否被 2 整除

if (num % 2 == 0) {
    cout << "此數能被2整除" << endl;
} else {
    cout << "此數不能被2整除" << endl;
}
