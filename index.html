成績及格判斷（>=60 分）主題解析

這是最經典的生活化選擇結構範例：輸入學期成績，如果大於或等於 60 分則判定為及格，否則為不及格。

1. 完整的 C++ 程式碼

#include<iostream>
using namespace std;
int main() {
    int score = 0;
    cout << "請輸入學期成績: ";
    cin >> score;
    
    if (score >= 60) {
        cout << "此學生成績及格" << endl;
    } else {
        cout << "此學生成績不及格" << endl;
    }
    return 0;
}

生活化進階範例：放颱風假標準判斷

當條件牽涉到「或者（Logical OR）」時，可以使用邏輯運算子 || 來組合多個條件。

氣象預報標準：「依據氣象預報，平均風力可達 7 級以上 或 陣風可達 10 級以上」即符合放假標準。

1. 對應的 C++ 程式碼

#include<iostream>
using namespace std;
int main() {
    int avgWind = 0;   // 平均風力級數
    int gustWind = 0;  // 陣風級數
    
    cout << "請輸入預報平均風力級數: ";
    cin >> avgWind;
    cout << "請輸入預報陣風級數: ";
    cin >> gustWind;
    
    // 使用邏輯運算子 || (OR) 結合兩個條件
    if (avgWind >= 7 || gustWind >= 10) {
        cout << "放颱風假" << endl;
    } else {
        cout << "不放颱風假" << endl;
    }
    return 0;
}

if 與 if...else 選擇結構架構說明

當程式需要依據條件成立與否來決定執行路徑時，就會使用選擇結構。

if (判斷條件) {
    // 條件成立（True）時執行此區塊
} else {
    // 條件不成立（False）時執行此區塊
}

認識關係與邏輯運算子

比較數值或組合多個條件的常用符號[cite: 1]：

運算子名稱說明
>=大於或等於檢查是否大於或等於指定數值[cite: 1]
&&邏輯與 (AND)多個條件必須同時成立，結果才為 True
||邏輯或 (OR)多個條件只要有一個成立，結果即為 True
