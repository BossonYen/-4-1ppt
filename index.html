1. 認識選擇結構與生活反思

思考：在學校生活中，是否有依據條件決定執行順序的例子？

例如：成績達 60 分為及格，未達 60 分則為不及格。

舉例反思（點擊按鈕顯示參考答案）：

情況： 體育課測驗 800 公尺跑步 測驗跑步速度

條件： 時間小於 240 秒 時間 <= 240秒

選擇結構問句： 如果跑步時間小於等於 240 秒則通過，否則不通過。 If (時間 <= 240) Pass Else Fail

2. 關係運算子 (Relational Operators)

電腦使用關係運算子比較兩個數值或變數：

符號運算子名稱範例
>大於5 > 1
<小於1 < 5
>=大於等於Price >= 100
<=小於等於Price <= 100
==等於 (相等)Price == 100
!=不等於5 != 1

比較結果只有兩種可能性：

  • 成立：回傳 True (內部儲存為 1)
  • 不成立：回傳 False (內部儲存為 0)

選擇結構 4-3

switch...case 介紹

多重條件選擇的優雅解法

💡 回顧：使用 if...else if...else 處理「範圍判斷」（例如：溫度 > 30 度）。

⚠️ 痛點：遇到「固定選項/特定數值」時（如選單按鍵 1, 2, 3），連串 else if 顯得冗長混亂。

✨ 解法：switch...case 能精準比對特定選項，大幅提升可讀性與執行效率！

switch...case 生活範例與語法

🛗 電梯按鈕

  • 按 「3」 樓 ➔ 精準停在 3 樓（無需判斷 > 10 或 < 0）。

  • 按 「2 號」 ➔ 掉出拿鐵咖啡。
  • 按未設定按鈕 ➔ 觸發 default 退回硬幣。

switch...case 語法結構

switch (控制表達式) {
  case 等值條件1:
    // 執行程式碼1
    break;
  case 等值條件2:
    // 執行程式碼2
    break;
  default:
    // 預設程式碼
    break;
}

總結

  • 固定值、多選項判斷 ➔ 優先使用 switch...case。
  • 範圍大小判斷 ➔ 使用 if...else if...else。
  • 關係運算子：== 代表相等、!= 代表不相等等。
  • 別忘了在每個 case 結束時加上 break;！
