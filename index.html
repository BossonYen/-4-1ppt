程式設計基礎：選擇結構 (if / if...else)

帶領你學會如何讓電腦自主判斷與做決定！

1. 程式如何判斷？認識關係運算子

在寫選擇結構之前，程式需要先學會「如何做比較」。比較的結果只有兩種可能性：

  • 成立：回傳 true（內部儲存為 1）
  • 不成立：回傳 false（內部儲存為 0）
符號運算子名稱範例說明
>大於5 > 1 (成立)
<小於1 < 5 (成立)
>=大於或等於成績 >= 60
<=小於或等於價格 <= 100
==等於（注意是兩個等號）價格 == 100
!=不等於5 != 1 (成立)

2. 單向選擇：if 敘述的架構與說明

語法架構：

if (判斷條件)
{
    // 當條件成立（True）時，才會執行的程式碼
    敘述主體;
}

說明：如果括號中的條件成立，就會執行大括號內的程式碼；若條件不成立，則直接跳過不執行。

動態體驗：判斷數字是否為正數

3. 雙向選擇：if...else 敘述的架構與說明

當程式面臨「二選一」的分歧路口時（例如：及格/不及格、偶數/奇數），就要使用 if...else。

語法架構：

if (判斷條件)
{
    // 條件成立（True）時執行此區塊
    敘述主體1;
}
else
{
    // 條件不成立（False）時執行此區塊
    敘述主體2;
}

動態體驗：奇偶數判斷 (num % 2 == 0)

4. ⚠️ 學生最易犯錯的 5 大觀念與寫程式陷阱

陷阱一：把「等於 (==)」誤寫成「指定 (=)」

錯誤示範：if (num = 5)

正確觀念：一個 = 是「指派數值」（把 5 塞給 num），兩個 == 才是「比較是否相等」。寫成一個等號會導致條件永遠視為成立（True），破壞程式邏輯。

陷阱二：條件判斷的小括号後面多加了分號 (;)

錯誤示範：if (score >= 60); { cout << "及格"; }

正確觀念：分號代表這一行敘述結束。如果在 if (...) 後面直接加分號，會導致 if 結東，後面的大括號區塊會變成「無條件執行」，失去選擇結構的意義。

陷阱三：混淆浮點數精確度與整數型態判斷

錯誤示範：像講義中企圖用 if (num = (int)num) 來判斷是否為整數，卻誤用成賦值運算子 =，且忽略了浮點數在電腦儲存時可能產生的微小誤差。

正確觀念：進行精確的數值比較與型態轉換時，運算子與括號範圍必須非常嚴謹。

陷阱四：忘記加上大括號 {} 導致程式邏輯範圍錯亂

錯誤示範：

if (weight > 90)
    cout << "體重過重";
    cout << "需要多運動"; // 這行不管 if 成立與否都會被執行！

正確觀念：如果 if 或 else 後面要控制多行程式碼，一定要用大括號 {} 包起來，否則只有緊跟著的那一行會受 if 控制。

陷阱五：搞錯複合條件的邏輯運算子 (&& 與 ||)

錯誤示範：想表達 BMI 介於 18.5 到 24 之間，卻寫成 if (BMI >= 18.5 || BMI < 24)。

正確觀念：「且」要用 &&（必須兩邊都符合），若用 ||（或）會變成只要小於 24 或是大於 18.5 就全部成立，導致條件形同虛設。
