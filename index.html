單向與雙向選擇結構

基礎邏輯判斷：if 與 if-else 敘述

1. 單向選擇結構 (if)

當程式滿足特定條件時才執行某段程式碼；若條件不成立，則直接跳過。 

if (條件式) {
    // 條件成立時執行的程式碼;
}
💡 點擊上方的程式碼行，即可查看詳細說明。

2. 雙向選擇結構 (if-else)

當條件成立時執行 A 區塊，條件不成立時則執行 B 區塊（二選一）。 

if (條件式) {
    // 條件成立執行的程式區塊 A;
} else {
    // 條件不成立執行的程式區塊 B;
}
💡 點擊上方的程式碼行，即可查看詳細說明。

Q1：判斷是否成年

請撰寫一段 C++ 程式碼，讀取使用者輸入的年齡 age，若年齡小於 18 歲，請印出 "Child"，否則印出 "Adult"。 

#include <iostream>
using namespace std;

int main() {
    int age;
    cin >> age;
    if (age < 18) {
        cout << "Child" << endl;
    } else {
        cout << "Adult" << endl;
    }
    return 0;
}

Q2：奇數與偶數判斷

輸入一個整數 num，請利用餘數運算子 % 與 if-else 判斷該數是奇數還是偶數。 

#include <iostream>
using namespace std;

int main() {
    int num;
    cin >> num;
    if (num % 2 == 0) {
        cout << num << " 是偶數" << endl;
    } else {
        cout << num << " 是奇數" << endl;
    }
    return 0;
}

Q3：折扣計算問題

某商店舉辦促銷活動：若消費總金額 total 滿 1000 元（含），即可享有 9 折優惠；否則維持原價。請計算並印出最終應付金額。 

#include <iostream>
using namespace std;

int main() {
    double total;
    cin >> total;
    if (total >= 1000) {
        total = total * 0.9;
    }
    cout << "最終應付金額：" << total << endl;
    return 0;
}

Q4：兩數求最大值 (Max)

輸入兩個整數 a 與 b，請利用 if-else 找到較大的數值並印出。 

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a > b) {
        cout << "較大值為：" << a << endl;
    } else {
        cout << "較大值為：" << b << endl;
    }
    return 0;
}

總結

  • 單向選擇 (if)：條件成立才執行，不成立則跳過。
  • 雙向選擇 (if-else)：二選一，條件成立執行 A，不成立執行 B。
  • 關係運算子：==、!=、>、<、>=、<=。

標準流程圖符號對照說明

在繪製程式邏輯時，不同的形狀代表不同的功能與意涵：

符號圖示 名稱 功能說明與範例
端點 起止符號 (Terminator) 代表流程的開始或結束（如：開始、結束）。
輸入/輸出 平行四邊形 (I/O) 代表資料的輸入或輸出（如：cin >> score）。
條件 菱形 (Decision) 進行條件判斷，依據「是(True)」或「否(False)」分流。
處理 矩形 (Process) 代表運算或資料處理（如：total = total * 0.9）。
檔案 檔案/文件 (Document) 代表檔案輸入/輸出或報表輸出（如：讀取 data.txt、產生紀錄檔）。
A 連接點 (Connector) 用於跨頁或複雜流程圖中連結不同區塊，避免線條交叉混亂。
