流程圖常用符號與元素說明

在動手寫程式之前，必須先在紙上繪製簡單的流程圖，讓程式的起始到結束邏輯清楚呈現。

符號名稱圖形外觀描述功能與用途說明
開始 / 結束符號圓角矩形 / 橢圓表示整個程式邏輯流程的起點（Start）或終點（End）。
程式執行方向箭頭 (Arrow)指示資料流動與程式指令執行的順序方向。
設定 / 程序長方形 (Rectangle)用來進行資料的運算、變數賦值或一般處理程序（例如：score = 0;）。
決策 / 條件菱形 (Diamond)用於選擇結構的條件判斷。通常會有兩條出路（True / False）。
輸出 / 輸入平行四邊形用來表示資料的輸入（如 cin）或結果的輸出（如 cout）。
連接點圓形 (Circle)當流程圖需要跨頁或線條過於繁雜時，用來連接不同區段的點。

成績及格判斷（>=60 分）主題解析

這是最經典的生活化選擇結構範例：輸入學期成績，如果大於或等於 60 分則判定為及格，否則為不及格。

1. 完整的 C++ 程式碼

#include<iostream>
using namespace std;
int main() {
    int score = 0;
    cout << "請輸入學期成績: ";
    cin >> score;
    
    if (score >= 60) {
        cout << "此學生成績及格" << endl;
    } else {
        cout << "此學生成績不及格" << endl;
    }
    return 0;
}

2. 流程圖架構說明

  • 起點：以「開始符號」啟動程式。
  • 輸入階段：使用「輸入/輸出符號」讀取使用者輸入的 score 變數。
  • 決策判斷：使用「菱形條件符號」進行判斷 score >= 60：
    • 若成立（True）：走向及格分支，輸出「此學生成績及格」。
    • 若不成立（False）：走向不及格分支，輸出「此學生成績不及格」。
  • 終點：兩條分支最後匯集，透過「結束符號」結束程式。

if 與 if...else 選擇結構架構說明

當程式需要依據條件成立與否來決定執行路徑時，就會使用選擇結構。

1. 單向選擇：if 敘述

if (判斷條件) {
    // 條件為 True 時才會執行的主體
}

說明：若括號內的條件成立，就執行大括號內的程式；若不成立，則直接跳過。

2. 雙向選擇：if...else 敘述

if (判斷條件) {
    // 條件成立（True）時執行此區塊
    敘述主體1;
} else {
    // 條件不成立（False）時執行此區塊
    敘述主體2;
}

說明：提供一個二選一的分歧路口。條件成立走 if，不成立則走 else，兩者必居其一。

認識關係運算子

比較兩個數值或變數之間的關係。比較的結果只有兩種可能性：成立回傳 true（內部為 1），不成立回傳 false（內部為 0）。

運算子符號名稱範例說明
>大於5 > 1 (成立)
<小於1 < 5 (成立)
>=大於或等於score >= 60
<=小於或等於price <= 100
==等於price == 100（注意是兩個等號）
!=不等於5 != 1 (成立)

⚠️ 學生最易犯錯的 5 大觀念與寫程式陷阱

陷阱一：把「等於 (==)」誤寫成「指定 (=)」

錯誤示範：if (num = 5)

正確觀念：一個 = 是賦值（把 5 塞給 num），兩個 == 才是比較相等。誤用單個等號會讓條件永遠成立，破壞邏輯。

陷阱二：條件判斷小括號後面多加了分號 (;)

錯誤示範：if (score >= 60); { cout << "及格"; }

正確觀念：分號代表敘述結束。如果在 if (...) 後面加分號，會導致 if 提前結束，後面的程式區塊會變成「無條件執行」。

陷阱三：忘記加上大括號 {} 導致程式範圍錯亂

錯誤示範：

if (weight > 90)
    cout << "體重過重";
    cout << "需要多運動"; // 這行不管 if 成立與否都會被執行！

正確觀念：若要控制多行敘述，必須用大括號 {} 包覆，否則只有緊跟著的第一行受 if 控制。

陷阱四：搞錯複合條件的邏輯運算子（&& 與 ||）

錯誤示範：想表達 BMI 介於 18.5 到 24 之間，卻寫成 if (BMI >= 18.5 || BMI < 24)。

正確觀念：「且」必須用 &&。若用 ||（或），條件會變成全部成立，形同虛設。

陷阱五：浮點數精確度與型態轉換迷思

正確觀念：在處理小數或強制轉型（如 (int)）時，電腦內部的二進位儲存可能產生微小誤差，設計條件時需特別注意數值精確度。
