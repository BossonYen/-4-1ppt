反思填空練習：[cite: 1]

  • 情況：考試成績結算[cite: 1]

💡 選擇結構定義：當我們希望依據條件成立與否來決定執行特定程式或順序時，即稱為選擇結構。[cite: 1]

🔢 關係運算子 (Relational Operators)

電腦使用「關係運算子」比較數值是否達到或低於標準[cite: 1]。比較結果只有兩種可能性[cite: 1]：

成立：回傳 True (電腦內部值為 1)[cite: 1]
不成立：回傳 False (電腦內部值為 0)[cite: 1]
符號運算子名稱範例代表意義
>大於5 > 1檢查 5 是否大於 1 (True)[cite: 1]
<小於1 < 5檢查 1 是否小於 5 (True)[cite: 1]
>=大於或等於Price >= 100Price 至少為 100[cite: 1]
<=小於或等於Price <= 100Price 至多為 100[cite: 1]
==等於 (注意是雙等號)Price == 100檢查 Price 是否剛好 100[cite: 1]
!=不等於5 != 1檢查 5 是否不等於 1 (True)[cite: 1]

✏️ 動手做練習：[cite: 1]

輸入一個數字，如果輸入的數字大於 0 則顯示正數，反之為負數[cite: 1]。

1. if 敘述 (單向選擇)[cite: 1]


#include <iostream>
using namespace std;

int main() {
    int num = 10;
    if (num > 0) {
        cout << "10為正數";
    }
    return 0;
}

👇 點擊按鈕進行逐行程式解析：

📋 語法格式[cite: 1]

if (判斷條件) {
    敘述主體;
}

如果條件成立，就會執行後面敘述；不成立則不會執行[cite: 1]。

👈 點擊左側按鈕即可觀看該行程式碼的詳細說明！

2. if...else 敘述 (雙向選擇)[cite: 1]


#include <iostream>
using namespace std;

int main() {
    int num = 0;
    cout << "請輸入一個整數: ";
    cin >> num;
    if ((num % 2) == 0) {
        cout << "此數能被2整除" << endl;
    } else {
        cout << "此數不能被2整除" << endl;
    }
    return 0;
}

👇 點擊按鈕進行逐行程式解析：

📋 語法格式[cite: 1]

if (判斷條件) {
    敘述主體1; /* 條件成立執行 */
} else {
    敘述主體2; /* 條件不成立執行 */
}
👈 點擊左側按鈕即可觀看該行程式碼的詳細說明！

Q1. 成績及格判斷：空格 A 應填入何者？[cite: 1]

if ( ______A______ ) { cout << "此學生成績及格"; }[cite: 1]

解答： score >= 60[cite: 1]
Q2. 體重判斷：體重超過 90kg 印出過重，反之正常。[cite: 1]
解答：
if (weight > 90) { cout << "此學生體重過重" << endl; }
else { cout << "此學生體重正常" << endl; }[cite: 1]
Q3. BMI 計算結果輸出：(weight=63.5, height=1.73)[cite: 1]
解答：
$BMI = 63.5 / (1.73^2) \approx 21.2169$[cite: 1]
因為 $18.5 \le 21.2169 < 24$ 條件成立[cite: 1]，故輸出：
此學生BMI正常，BMI結果為: 21.2169[cite: 1]
