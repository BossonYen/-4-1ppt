成績及格判斷（>=60 分）主題解析

這是最經典的生活化選擇結構範例：輸入學期成績，如果大於或等於 60 分則判定為及格，否則為不及格。

1. 完整的 C++ 程式碼

#include<iostream>
using namespace std;
int main() {
    int score = 0;
    cout << "請輸入學期成績: ";
    cin >> score;
    
    if (score >= 60) {
        cout << "此學生成績及格" << endl;
    } else {
        cout << "此學生成績不及格" << endl;
    }
    return 0;
}

生活化進階範例：放颱風假標準判斷

當條件牽涉到「或者（Logical OR）」時，可以使用邏輯運算子 || 來組合多個條件。

氣象預報標準：「依據氣象預報，平均風力可達 7 級以上 或 陣風可達 10 級以上」即符合放假標準。

1. 對應的 C++ 程式碼

#include<iostream>
using namespace std;
int main() {
    int avgWind = 0;   // 平均風力級數
    int gustWind = 0;  // 陣風級數
    
    cout << "請輸入預報平均風力級數: ";
    cin >> avgWind;
    cout << "請輸入預報陣風級數: ";
    cin >> gustWind;
    
    // 使用邏輯運算子 || (OR) 結合兩個條件
    if (avgWind >= 7 || gustWind >= 10) {
        cout << "放颱風假" << endl;
    } else {
        cout << "不放颱風假" << endl;
    }
    return 0;
}

if 與 if...else 選擇結構架構說明

當程式需要依據條件成立與否來決定執行路徑時，就會使用選擇結構。

if (判斷條件) {
    // 條件成立（True）時執行此區塊
} else {
    // 條件不成立（False）時執行此區塊
}

認識完整的關係與邏輯運算子

在寫條件判斷時，我們需要使用各種運算子來比較數值或組合條件：

運算子名稱說明與範例
==等於檢查兩邊是否相等，例如：x == 5
!=不等於檢查兩邊是否不相等，例如：x != 0
>大於檢查左邊是否大於右邊，例如：score > 60
<小於檢查左邊是否小於右邊，例如：age < 18
>=大於或等於檢查左邊是否大於或等於右邊，例如：score >= 60
<=小於或等於檢查左邊是否小於或等於右邊，例如：weight <= 50
&&邏輯與 (AND)多個條件必須同時成立，結果才為 True
||邏輯或 (OR)多個條件只要有一個成立，結果即為 True
!邏輯非 (NOT)將條件的反向結果顛倒（True 變 False，False 變 True）

講義原版程式範例與互動測試

int num = 10;
if (num > 0) {
    cout << "10為正數";
}

⚠️ 學生最易犯錯的 5 大觀念與寫程式陷阱

陷阱一：把「等於 (==)」誤寫成「指定 (=)」

一個 = 是賦值（把右邊的值存入左邊），兩個 == 才是比較相等。例如寫成 if (x = 5) 會讓 x 變成 5 且條件永遠成立，正確應為 if (x == 5)。

陷阱二：條件判斷式後面不小心加上分號 (;)

例如寫成 if (score >= 60); { cout << "及格"; }。因為 if 後面多了分號，會導致後方的程式區塊變得與 if 無關，無論成績多少都會執行輸出。

陷阱三：單行敘述省略大括號 ({}) 導致邏輯範圍混淆

雖然 if 後方如果只有一行指令可以省略大括號，但日後若想新增第二行指令卻忘記補上大括號，就會造成只有第一行受 if 控制的嚴重邏輯錯誤。

陷阱四：巢狀 if...else 的階層與對齊錯亂

當多個 if...else 互相包夾（巢狀結構）時，else 總是會與最近且尚未配對的 if 進行結合。如果沒有做好縮排對齊，極容易造成邏輯判斷對象錯亂。

陷阱五：數學上的連續範圍直接寫入程式（例如 0 < x < 10）

在數學中常寫 0 < x < 10，但在 C++ 中不能這樣直接連寫。必須使用邏輯運算子將其拆開並正確組合：(x > 0 && x < 10)。
